# God's Clay Media — Campaign Artwork

**Media and campaign asset repository | LX Obsidian Labs**

This repository contains image assets, including sequentially named `african-intelligence-*.jpg` files. It is an **asset collection**, not an application or a software release.

## Usage and provenance

- Confirm ownership and permission to publish, reproduce or modify each image before reuse.
- Do not infer that all files are freely licensed merely because the repository is public.
- Keep source artwork, approval status, export dimensions and intended use documented before producing derivative marketing material.
- Avoid storing personal information, private client briefings or unreleased commercial content in public files.

## Recommended asset manifest

For each approved image, record filename, campaign, creator/rights holder, dimensions, approval date, allowed channels and replacement history. These details are **not yet verified** by this README.

## Technical checks

Validate filenames, image sizes, color profiles, visual consistency and accessibility alternatives when images are embedded on websites.
